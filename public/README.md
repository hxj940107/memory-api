# Legacy Web Prototype

This directory contains the historical browser prototype for XiaoC Private.

It is **not** the new Public App. The Public App is a separate Own Stack product
and must be created in its own repository. Do not add Public App account flows,
tenant UX, onboarding, or product features here.

Shared Backend work may continue in this repository only when Private/Public
identity, persona, Memory, Storage, and business data remain correctly isolated.
