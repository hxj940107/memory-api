# Moments 相册场景筛选（2026-11-01）

本地实现，待部署。聊天触发和低频自主 consideration 复用 metadata-only 排序：授权 owner 的 shared/enabled/未归档照片最多读取 200 条，按对话素材与照片描述的双字片段、分类和少量场景同义词排序；同分沿用未使用优先、较新优先。

聊天路径最多向原调用提供 8 张相册照片，自主路径最多 6 张。聊天路径先排除最近使用照片，再截取候选；明确指定的相册照片继续走原指定路径。候选排序不证明同一事件，不覆盖事实、授权、天气或时段验证，也不要求模型选图。无相关性时沿用原排序，匹配是轻量规则而非语义模型；超过扫描上限的照片仍可能不入池。

不新增模型调用，不传原图，不修改发布时间或发布逻辑，不做延迟发布前补图。数据库读取 metadata 数量增加，但模型候选数量不增加；实际 token 长度仍取决于照片描述。既有朋友圈不回填图片。

验证：69 项 Moments / shared album 定向测试通过，JS syntax 与 diff 检查通过，API Function 保持 12 个。未进行线上模型调用或线上数据修改。
